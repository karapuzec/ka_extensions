Twig-шаблоны (русская версия раздела)
=====================================

Текст шаблона, заданный в событии ``view/*/before``
---------------------------------------------------

В OpenCart обработчик события ``view/<route>/before`` может подменить текст шаблона через третий
аргумент ``$code``: Template\Twig выводит ``$code`` вместо файла.

С Ka Extensions загрузчик витрины сначала ищет шаблон в своих папках: кэш kamod (kapatch и дочерние
шаблоны модулей), копии редактора тем (``system/storage/theme.kamod``) и файлы модификаций OCMOD
(``system/storage/modification``). Если для шаблона есть такой файл, выводится он, а **текст из**
``$code`` **игнорируется**. ``$code`` используется только для шаблона без таких файлов. С ka_speedup
(одно окружение Twig на все шаблоны запроса) ``$code`` игнорируется у всех шаблонов, кроме первого.

Правки из «Дизайн > Редактор шаблона» тоже не приходят в ``$code``: Ka Extensions берёт их из
``system/storage/theme.kamod``, ядровое событие ``event/theme`` ничего не получает из базы.

Чтобы изменить шаблон, используйте kapatch или дочерний шаблон kamod (см. :doc:`../overriding_core_files`),
они применяются вместе с изменениями других модулей. Чтобы изменить результат шаблона, используйте
событие ``view/<route>/after`` (``$output``).
